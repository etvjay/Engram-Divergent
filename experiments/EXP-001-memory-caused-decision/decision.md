# EXP-001 Decision

## Decision

ACCEPT the controlled memory-caused-decision mechanism as a tested Engram invariant for the current deterministic workload.

## Consequences

1. The runtime causal spine remains the canonical demonstration path.
2. `CHANGED_ACTION` must continue to require explicit influence provenance and a counterfactual under the active policy.
3. Retrieval alone must never be presented as causal influence.
4. Later success alone must never be presented as proof that a memory was beneficial.
5. External venue execution remains explicitly SIMULATED.
6. Cloud integrations are promoted independently only after credentialed external verification.
7. Future workload adapters must preserve the same proof chain rather than invent framework-specific causality semantics.

## Next experiment class

The next evaluation should test memory quality rather than merely memory causality: introduce stale, contradictory, low-confidence, or harmful memories and verify that policy/evaluation mechanisms reject, downgrade, or identify them without erasing historical evidence.
